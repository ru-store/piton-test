# Игра "Змейка" на Python

Классическая игра "Змейка", написанная на Python с использованием библиотеки pygame.

## Особенности игры

- Красивая графика с шахматным фоном
- Плавное движение змеи
- Система подсчета очков
- Проверка столкновений со стенами и собой
- Управление стрелками клавиатуры

## Установка и запуск

### Способ 1: Автоматический запуск
```bash
python3 run_game.py
```

### Способ 2: Ручная установка
1. Установите зависимости:
```bash
# Ubuntu/Debian:
sudo apt update && sudo apt install -y python3-pygame

# Или через pip:
pip install -r requirements.txt
```

2. Запустите игру:
```bash
python3 snake_game.py
```

### Способ 3: Демонстрационная версия (без графики)
```bash
python3 snake_demo.py
```

## Файлы проекта

- `snake_game.py` - основная игра с графикой pygame
- `snake_demo.py` - демонстрационная версия в терминале
- `run_game.py` - скрипт запуска с проверкой зависимостей
- `requirements.txt` - список зависимостей

## Управление

- **↑** - движение вверх
- **↓** - движение вниз
- **←** - движение влево  
- **→** - движение вправо

## Правила игры

- Управляйте змеей, собирая красную еду
- За каждую съеденную еду змея растет и вы получаете очко
- Избегайте столкновений со стенами и собственным телом
- Цель - набрать как можно больше очков
