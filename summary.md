# Алгоритм линейной регрессии - Краткое резюме

## 🎯 Что вы изучили

### 1. Основы линейной регрессии
- **Цель**: найти линейную зависимость между входными данными и целевой переменной
- **Формула**: `y = w₀ + w₁x₁ + w₂x₂ + ... + wₙxₙ`
- **Применение**: предсказание непрерывных значений (цены, зарплаты, температура и т.д.)

### 2. Математика
- **Функция потерь**: MSE = (1/2m) * Σ(y_pred - y_true)²
- **Градиентный спуск**: обновление весов для минимизации ошибки
- **Параметры**: веса (коэффициенты) и смещение (intercept)

## 🔧 Практические советы

### Подготовка данных
- Нормализуйте признаки (особенно если они в разных масштабах)
- Проверьте на выбросы
- Убедитесь в линейной зависимости

### Выбор параметров
- **Learning rate**: 0.01-0.1 (обычно)
  - Слишком большой → модель не сходится
  - Слишком маленький → медленное обучение

### Оценка качества
- **MSE** (Mean Squared Error) - средняя квадратичная ошибка
- **R²** (коэффициент детерминации) - показывает долю объясненной дисперсии
- **MAE** (Mean Absolute Error) - средняя абсолютная ошибка
